# ADR 005-pwa: PWA với offline fallback an toàn

Ngày: 15/11/2026

Trạng thái: Accepted

## Bối cảnh
UI cần mobile-first, installable và thông báo mất mạng.

## Quyết định
Manifest + PNG icons; service worker chỉ fallback navigation, không cache API riêng tư hoặc tự replay thanh toán.

## Hệ quả/trade-off
Giỏ cục bộ vẫn có; menu/order cần mạng; đăng ký SW chỉ production.
